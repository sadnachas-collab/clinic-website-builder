Причина найдена: вход не срабатывает не из-за логина/пароля, а потому что весь JavaScript админки падает при загрузке с ошибкой `SyntaxError: Unexpected end of input` в конце `public/clinic-admin.html`. Из-за этого функция `handleLogin` не регистрируется, форма ведёт себя как обычная HTML-форма: экран «дёргается», поля очищаются, вход не происходит.

План исправления:

1. Восстановить синтаксически целый JS-блок в `public/clinic-admin.html`
   - найти незакрытую конструкцию в конце скрипта;
   - закрыть недостающую скобку/функцию так, чтобы браузер мог выполнить весь скрипт;
   - проверить `node --check` для извлечённого JS-блока.

2. Убрать вторую потенциальную причину повторения ошибки
   - заменить оставшиеся небезопасные `JSON.parse(localStorage.getItem(...))` для данных админки на безопасное чтение с fallback;
   - это защитит вход от битых данных в `localStorage`, чтобы одна повреждённая запись больше не ломала всю админку.

3. Сделать вход устойчивым
   - сохранить аварийный доступ `admin / 123456`;
   - гарантировать, что submit формы всегда перехватывается;
   - при ошибке пароля не очищать поля.

4. Проверить в браузере
   - открыть `/admin`;
   - ввести `admin` / `123456`;
   - убедиться, что открывается админ-панель;
   - проверить консоль на отсутствие `SyntaxError`.

После подтверждения внесу только эти правки, дизайн и структуру админки не трогаю.
