# Редактирование админов в разделе «Управление доступом»

Сейчас в разделе можно только добавить или удалить пользователя. Добавим возможность редактировать существующих.

## Что можно будет менять

Для каждого админа — кнопка «Редактировать», по которой строка переходит в режим правки. Доступные поля:

- **Отображаемое имя** (`display_name`)
- **Роль** — `Владелец` / `Редактор` (select)
- **Новый пароль** — опционально, если поле пустое, пароль не меняется

Логин (email) менять нельзя — это идентификатор учётки.

## Защиты (на сервере)

- Только владелец (`owner`) может редактировать других.
- Нельзя снять роль `owner` с самого себя (иначе можно остаться без владельцев).
- Нельзя снять роль `owner` с последнего владельца в системе.
- Пароль ≥ 6 символов; имя ≤ 100 символов.

## Технические детали

1. **`src/lib/admins.functions.ts`** — новая server function `updateAdmin`:
   - Вход: `{ userId, displayName?, role?, newPassword? }` (Zod-валидация).
   - Проверка, что вызывающий — `owner`.
   - Если меняется роль и снимается `owner` — проверить количество владельцев и self-check.
   - `supabaseAdmin.auth.admin.updateUserById` для пароля.
   - `update admin_profiles` для `display_name`.
   - `delete` + `insert` в `user_roles` при смене роли.

2. **`src/routes/admin.tsx`** — добавить `updateAdmin` в импорты и в обработчик `admin-rpc-call` (новый `action: "updateAdmin"`).

3. **`public/clinic-admin.html`** — в разделе админов:
   - У каждой карточки добавить кнопку «Редактировать» (карандаш).
   - В режиме редактирования: поля `display_name`, select роли, поле «Новый пароль» (плейсхолдер «оставьте пустым, чтобы не менять»), кнопки «Сохранить» / «Отмена».
   - `saveAdmin` для существующих записей вызывает `parentRpc('updateAdmin', {...})` → `loadAdmins()` + тост.
   - Текущего пользователя (owner-self) тоже можно редактировать: имя — да, роль — нет (disabled), пароль — через существующий `changeOwnPassword`.

## Что НЕ меняем

- Логин / email пользователя.
- Схему БД, RLS, бакеты, остальные разделы админки.
- Существующие функции `createAdmin` / `deleteAdmin` / `listAdmins` / `changeOwnPassword`.
