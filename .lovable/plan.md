## Что реализую

Минимальный пакет соответствия 152-ФЗ / 420-ФЗ для `public/clinic-site.html` + связка с `public/clinic-admin.html`.

### 1. Cookie-баннер (новый блок внизу страницы)
- Фиксированная плашка снизу, появляется если в `localStorage` нет ключа `cookie-consent`.
- Текст: «Мы используем файлы cookie для работы сайта и аналитики (Яндекс.Метрика). Подробнее — в Политике конфиденциальности.»
- Кнопки: **«Принять все»**, **«Только необходимые»**, ссылка **«Политика конфиденциальности»** (открывает существующую модалку).
- Сохраняет выбор `{ analytics: true|false, ts: ... }` в `localStorage`.
- Заглушка-комментарий `<!-- здесь подгружать Я.Метрику только если analytics=true -->` — реального счётчика на сайте сейчас нет, добавлю условную обёртку для будущего кода.

### 2. Чекбокс согласия на ПДн в форме записи
- Найду форму записи на приём, добавлю **обязательный непредзаполненный** `<input type="checkbox" required>` перед кнопкой «Отправить».
- Текст: «Я даю согласие на обработку персональных данных в соответствии с [Согласием] и ознакомлен(а) с [Политикой конфиденциальности]» — обе ссылки открывают модалки.
- Без галочки кнопка submit не срабатывает (HTML5 `required` + JS-проверка).

### 3. Новая модалка «Согласие на обработку персональных данных»
- Отдельный документ по 152-ФЗ (что обрабатываем, цели, сроки, права субъекта, как отозвать).
- Кнопка открытия — в подвале рядом с «Политикой» и «Пользовательским соглашением», и из чекбокса формы.

### 4. Возрастная маркировка 18+
- Значок «18+» в подвале (текстовый, в рамке), рядом с реквизитами.

### 5. Кнопка «Управление cookies» в подвале
- Ссылка «Настройки cookies» — сбрасывает `localStorage.cookie-consent` и показывает баннер заново.

### 6. Заглушки реквизитов в админке
Добавлю в `clinic-admin.html` в раздел настроек поля (с пометкой «заполнить реальными данными»):
- Номер уведомления в реестре операторов ПДн (РКН)
- ФИО + email ответственного за обработку ПДн
- Полные реквизиты лицензии (№, дата, орган выдачи, ссылка на реестр)
- ИНН, КПП, юр. адрес, фактический адрес, email

Эти поля будут читаться/выводиться в подвал сайта и в текст модалок Политики/Согласия (через те же `data-*` подстановки, что уже используются для прайса/контактов, если такой механизм есть; иначе оставлю как статичные плейсхолдеры с TODO-комментарием).

### Чего НЕ трогаю
- Сетку отзывов, кнопки Яндекс/2GIS/ПроДокторов, MAX-виджет, прайс, мобильное меню, `src/`, дизайн-токены.
- Не подключаю реальную Яндекс.Метрику (её сейчас нет — только готовлю условную обёртку).
- Не меняю существующие модалки Политики и Пользовательского соглашения по содержанию (только добавляю ссылки на новую модалку Согласия).

### Технические детали
- Всё на ванильном HTML/CSS/JS внутри `public/clinic-site.html` (как остальной сайт).
- Стили — через существующие Tailwind-классы, без новых внешних зависимостей.
- Cookie-баннер: `position: fixed; bottom: 0; z-index: 60;` чтобы не перекрывать мобильное меню (которое выше по z-index).
- Состояние согласия: один ключ `localStorage` — `cookie-consent` (JSON).
