## Что добавляем

Новый редактируемый блок на главной странице — секция «Философия» (`<section id="about">` в `public/clinic-site.html`, строки 512–546). Сейчас имя врача, должность, аватарка, большое фото и play-кнопка зашиты в HTML.

## Поля в админке

В разделе **«Главная страница»** добавится отдельная карточка **«Философия — врач и видео-визитка»** с полями:

1. **Имя врача** (под цитатой) — текст
2. **Должность** (под именем, например «Главный врач, основатель») — текст
3. **Маленькая аватарка** (круглая, рядом с именем) — загрузка фото
4. **Большое фото** (правая колонка, аспект 4:5) — загрузка фото
5. **Видео-визитка** (необязательно) — ссылка (mp4 / YouTube / Vimeo)
   - Если задано → по клику на большое фото открывается видео; play-кнопка остаётся.
   - Если пусто → большое фото без play-кнопки, клик ничего не делает.

Заголовок «Мы не меняем черты лица…» и текст под ним уже редактируются в существующем блоке «О клинике» — их не трогаем.

## Хранение

Новых таблиц не создаём. Данные кладём в существующую таблицу `page_content` под ключом `home_about_doctor` (jsonb со всеми 5 полями). Фото загружаем в существующий бакет `photos`.

## Изменения в коде

1. **`public/clinic-admin.html`** — добавить в раздел «Главная страница» новый блок «Философия — врач и видео-визитка» с 5 полями (текст × 2, загрузка фото × 2, ссылка × 1) и кнопкой «Сохранить». Сохранение → `upsert` в `page_content` (ключ `home_about_doctor`).
2. **`public/clinic-site.html`** — заменить захардкоженные значения в `<section id="about">` на чтение из `page_content.home_about_doctor`:
   - имя/должность → текст;
   - `<img>` аватарки и большого фото → URL из БД (с фолбэком на текущие, если пусто);
   - `onclick` на большом фото → если есть ссылка на видео, открывать модалку с `<video>` / iframe YouTube; иначе ничего.
3. **`public/clinic-site-data.js`** — добавить загрузку `home_about_doctor` из `page_content` при инициализации.

## После внедрения

Открываешь админку → «Главная страница» → блок «Философия — врач и видео-визитка» → загружаешь оба фото, вписываешь имя/должность, при желании добавляешь ссылку на видео → «Сохранить». Сайт сразу подхватит.
