## Подключение виджета онлайн-записи DIKIDI

Заменяем текущее самописное модальное окно «Записаться» на переход в систему онлайн-записи DIKIDI (открытие в новой вкладке).

### Что меняется

Файл: `public/clinic-site.html` (один файл, фронтенд)

1. **Константа со ссылкой DIKIDI**
   В блоке `<script>` (рядом с `openBooking`) добавляем:
   ```js
   const DIKIDI_URL = 'https://dikidi.net/#widget=209876';
   ```
   Один источник правды — если заказчик пришлёт новый ID, меняется в одном месте.

2. **Функция `openBooking`**
   Полностью переписываем — больше не открывает модалку, а открывает DIKIDI в новой вкладке:
   ```js
   function openBooking() {
     window.open(DIKIDI_URL, '_blank', 'noopener,noreferrer');
   }
   ```
   Параметры `service` / `doctor` больше не нужны (клиент выбирает врача и услугу внутри DIKIDI), но сигнатуру оставляем совместимой — все существующие вызовы `openBooking('что-то')` продолжат работать.

3. **Кнопка «Записаться к врачу» в модалке врача**
   В функции `openDoctor` обработчик кнопки уже сводится к `openBooking(...)` — автоматически начнёт открывать DIKIDI. Дополнительно закрываем модалку врача перед открытием новой вкладки, чтобы пользователь не возвращался на застывшую модалку.

4. **Скрипт DIKIDI**
   Подключение `https://dikidi.net/assets/js/widget_record/widget2.min.js` для варианта «новая вкладка» **не требуется** — этот скрипт нужен только для встроенного модального виджета на самом сайте. Поскольку мы открываем DIKIDI на их домене, скрипт не подключаем (меньше внешних запросов, быстрее загрузка).

5. **Удаление неиспользуемого кода**
   - Удаляем HTML модального окна `#booking-modal` (строки ~30-55) — больше не используется.
   - Удаляем функцию `submitBooking` — больше не нужна.
   - HTML модалки согласия/политики (`consent-modal`, `policy-modal`) **оставляем** — они открываются из других мест (футер, cookie-баннер).

### Что НЕ меняется

- Внешний вид всех кнопок «Записаться» — стилистика премиальная, остаётся как есть.
- Плавающая кнопка справа снизу, hero-кнопки, кнопки в карточках процедур, в прайсе, в карточках акций, в карточке врача — все триггерят одну и ту же логику `openBooking()`.
- Админка (`public/clinic-admin.html`) — не трогаем, ссылка захардкожена.
- Раздел контактов (VK / Telegram / MAX) — не трогаем.

### Поведение для пользователя

Клик по любой кнопке «Записаться» → открывается новая вкладка с виджетом DIKIDI клиники, текущая вкладка сайта остаётся открытой. Клиент выбирает врача, услугу, дату и подтверждает запись через СМС-код прямо в DIKIDI.

### Заметка для заказчика

После публикации стоит напомнить: для работы СМС-подтверждения DIKIDI требует положительный баланс СМС в личном кабинете dikidi.net.
