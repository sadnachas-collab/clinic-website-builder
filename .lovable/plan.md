## Проблема

В админке в карточках предпросмотра (FAQ и аналогичные блоки — отзывы, акции, «О клинике», описания процедур, юр. документы) длинный текст без пробелов («фывфывыфвфв…») не переносится и вылезает за правый край карточки/экрана. Видно на скрине во вкладке «Главная → Частые вопросы».

Причина: у `<p>` с текстом ответа стоит только `text-sm text-gray-600 leading-relaxed` — нет правил переноса. Tailwind по умолчанию не ломает «слова» без пробелов, и кириллический «мусор» уезжает за пределы родителя, потому что карточка — flex-контейнер и не ограничивает min-width детей.

## Что сделаем

Точечная правка `public/clinic-admin.html`, только верстка предпросмотра в админке. Контент сайта, логика сохранения и Quill не трогаем.

1. **Глобальное правило в `<style>` админки** — добавить класс-помощник:
   ```css
   .admin-wrap-anywhere { overflow-wrap: anywhere; word-break: break-word; }
   ```
   и применить его (через общий селектор) ко всем `view-mode`-параграфам в списках админки: FAQ, отзывы, акции, специалисты, услуги, процедуры (краткое описание в карточке), документы. На уровне CSS достаточно одного селектора вида:
   ```css
   #admin-faq-list p,
   #admin-reviews-list p,
   #admin-promos-list p,
   #admin-specialists-list p,
   #admin-services-list p,
   #admin-procedures-list p { overflow-wrap: anywhere; word-break: break-word; }
   ```
   Точный список id-контейнеров уточню по месту при правке (по `id="admin-…-list"`).

2. **Защита самих flex-карточек от «выпадения» детей**:
   карточкам списков добавить `min-w-0` (или в CSS `min-width: 0`) у текстовых колонок внутри `flex` — это стандартный фикс «текст вылезает за пределы flex-родителя».

3. **FAQ конкретно (строки 986–1000)**:
   - на `<div id="faq-row-…" class="flex flex-col …">` ничего менять не нужно (это уже `flex-col`).
   - на `<p class="font-bold text-brand-900 pr-4">${f.q}</p>` (вопрос) и `<p class="text-sm text-gray-600 view-mode leading-relaxed">${f.a}</p>` (ответ) добавить класс `break-words` (Tailwind) + полагаться на общий CSS-помощник для совсем «слипшихся» строк.
   - на контейнер `<div class="flex justify-between items-center view-mode">` (заголовок + кнопки) добавить `min-w-0` к левой колонке, чтобы кнопки справа не выдавливались.

## Чего не трогаем

- Логику FAQ (`renderFaq/saveFaq/editFaq`), `persistData`, `localStorage`.
- Quill-редактор и панель форматирования.
- Сайт `public/clinic-site.html` и его FAQ-секцию (там перенос уже работает корректно, но если попросишь — отдельной задачей проверю).
- Какие-либо обработчики «Сохранить» и недавнюю защиту `saveGuard`.

## Проверка

1. `/admin` → «Главная» → «Частые вопросы»: длинная строка «фывфыв…» переносится внутри карточки, кнопки «изменить/удалить» остаются на месте справа.
2. Те же проверки в «Отзывы», «Акции», «Специалисты», «Услуги», «Процедуры» — длинный текст без пробелов не вылезает за карточку.
3. Обычный текст (с пробелами) выглядит как раньше — переносы по словам, без «рваных» строк.
