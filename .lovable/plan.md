Проверил: файл в базе есть, ссылка сохранена такая:
`/storage/v1/object/public/documents/price/...pdf`

Вероятная причина белого экрана: кнопка «Просмотр» сейчас открывает прямой публичный URL файла на домене backend. Для PDF/файлов это ненадёжно: браузер может открыть пустую вкладку, если Storage отдаёт файл без корректного режима отображения/заголовков или если Safari не отрисовывает PDF по прямой ссылке. Ошибок в консоли при этом может не быть — это совпадает со скрином.

План исправления:

1. Не открывать файл напрямую через `window.open(file_url)`.
2. Сделать нормальный просмотр внутри админки:
   - при нажатии «Просмотр» открывать модальное окно;
   - для PDF показывать встроенный `<iframe>`/`object` с файлом;
   - для изображений показывать `<img>`;
   - для Excel/других файлов показывать понятную панель с кнопкой «Скачать», потому что браузер не обязан уметь их просматривать.
3. Добавить запасной сценарий:
   - если файл не отрисовался, показывать кнопку «Открыть/скачать файл»;
   - не выкидывать пользователя из админки и не открывать пустую вкладку.
4. Исправить состояние кнопки:
   - если файла нет — «Просмотр» неактивен;
   - если файл есть — видно имя файла и доступны «Просмотр»/«Скачать».
5. Дополнительно проверить, что после загрузки в `price_files` сохраняется актуальный URL и интерфейс сразу обновляется.

Технически менять нужно в `public/clinic-admin.html`: функции `renderPriceFile`, `viewPriceFile`, возможно добавить `downloadPriceFile` и разметку модального просмотра.
