## Загрузка видео-визитки с компьютера

Сейчас в админке поле «видео» — это текстовый input для ссылки (YouTube/Vimeo/mp4). Заменим на гибрид: можно либо загрузить файл с компа, либо вставить внешнюю ссылку.

### 1. Supabase Storage
- Используем существующий бакет `photos` (он уже public), папка `about-doctor/video/`.
- Лимит размера файла: **50 МБ** (валидация на клиенте, чтобы не упирались в лимиты Supabase и не грузили тяжёлое).
- Допустимые типы: `video/mp4`, `video/webm`, `video/quicktime` (.mov).
- При замене видео — старый файл удаляем из бакета (как уже сделано для фото).

### 2. `public/clinic-admin.html` — блок «Философия — врач»
В поле «Видео-визитка» добавить:
- Кнопку **«Загрузить видео с компьютера»** (`<input type="file" accept="video/mp4,video/webm,video/quicktime">`).
- Под ней — превью загруженного видео (`<video controls>` с текущим URL) + кнопка «Удалить».
- Отдельное текстовое поле **«Или вставьте ссылку (YouTube/Vimeo/mp4)»** — на случай, если хотят встроить внешнее видео без загрузки.
- Индикатор прогресса загрузки (текст «Загрузка… X%» — через простой XHR или просто «Загрузка…»).
- Валидация: тип файла + размер ≤ 50 МБ, иначе toast с ошибкой.

Логика сохранения в `saveAboutDoctor()`: поле `video` в jsonb остаётся одно (строка-URL). Если загружен файл — пишем URL из Storage; если введена ссылка — пишем её. Если оба пустые — кнопка play на сайте не показывается.

### 3. `public/clinic-site-data.js` — `openAboutDoctorVideo()`
Уже умеет различать YouTube/Vimeo iframe vs `<video>` для mp4. Добавим: если URL заканчивается на `.webm` / `.mov` или содержит `/storage/v1/object/public/photos/about-doctor/video/` → использовать `<video controls autoplay>`. Никаких изменений в `clinic-site.html` не нужно.

### 4. Что НЕ трогаем
- Бакет `photos` уже создан и public — миграции не нужны.
- Структура `page_content.home_about_doctor` не меняется (поле `video` как было строкой, так и остаётся).
- Никакой серверной логики (server functions, edge functions) — всё через прямой `supabase.storage.from('photos').upload(...)` из браузера, как уже работает для фото.
- Timeweb-хостинг: фронт/админка — статика, видео отдаётся напрямую с домена Supabase Storage по public URL. Переезд на Timeweb ничего не ломает.

### Технические детали
- Файлы: только `public/clinic-admin.html` и `public/clinic-site-data.js`.
- Имя файла в Storage: `about-doctor/video/<timestamp>-<random>.<ext>` (чтобы не было коллизий).
- При удалении видео из админки — `supabase.storage.from('photos').remove([path])` + очистка поля в jsonb.

### Открытый вопрос
Лимит 50 МБ ок? Если нужно больше (например 200 МБ под HD-визитку 1–2 минуты) — скажи, поставлю другой. Бóльшие файлы лучше всё-таки заливать на YouTube/Vimeo и вставлять ссылкой.
