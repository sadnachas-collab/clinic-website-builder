## Проблема

В админке есть несколько мест, где загружают файл/фото, но нельзя проверить, что именно загружено:

1. **Прайс-лист (Документ)** — `Загрузить новый` / `Удалить`, нет просмотра. Кроме того, сейчас в `handleFileUpload` сохраняются только `name` и `size` файла, **сам файл нигде не хранится** — открыть его потом физически невозможно.
2. **Интерьер** (`renderInterior`) и **Юр. документы / лицензии** (`renderDocs`) — изображения вставляются по URL, в карточке есть только кнопка «удалить» на hover. Превью маленькое — открыть в полный размер нельзя.
3. **Фото специалистов** (`spec-img-…` в `renderSpecialists`) — поле URL и тумбочка-аватар. Просмотра в полный размер нет.

## Что сделаем (только `public/clinic-admin.html`)

### 1. Прайс-лист — реальное хранение + просмотр

- В `handleFileUpload(e)` читать файл через `FileReader.readAsDataURL`, сохранять в `dbPriceFile` поля `{name, size, exists, dataUrl, mime}`. Писать в `localStorage` как сейчас. Предупредить только в комментарии: ограничение ~5 МБ из-за localStorage; при превышении показать `showToast('Файл слишком большой для хранения в браузере')` и не сохранять.
- В разметке (строки 411–415) добавить кнопку «глаз» (`<i data-lucide="eye">`) `onclick="viewPriceFile()"` ПЕРЕД «Загрузить новый». Кнопка `disabled` (серая) пока `!dbPriceFile.exists`.
- Новая функция `viewPriceFile()`:
  - если есть `dataUrl` — открыть его в новой вкладке (`window.open(dataUrl, '_blank')`); браузер сам отрисует PDF / скачает DOCX;
  - если в `dbPriceFile` только старые поля без `dataUrl` (легаси-запись «price.pdf / 2.4 MB» из дефолта) — показать `showToast('Файл не загружен. Нажмите «Загрузить новый», чтобы добавить.')`.
- `renderPriceFile()` обновить: переключать `disabled` у кнопки «глаз» по `dbPriceFile.exists && dbPriceFile.dataUrl`.

### 2. Интерьер и Юр. документы — просмотр в полный размер

В `renderInterior` (стр. 985-993) и `renderDocs` (стр. 994-1002) рядом с кнопкой «корзина» на hover добавить кнопку «глаз» — `onclick="openImagePreview('${i.img}')"`.

Новая утилитарная функция `openImagePreview(url)`:
- создаёт (один раз) лайтбокс-оверлей `#admin-image-preview` поверх всего: затемнение, центрированная `<img>` с `max-w-[90vw] max-h-[90vh]`, кнопка закрытия и клик по фону = закрыть, Esc = закрыть;
- подставляет `src = url` и показывает.

Стили лайтбокса — в существующий `<style>` блок.

### 3. Фото специалистов

В `renderSpecialists` рядом с превью-аватаром (или в edit-режиме рядом с полем `spec-img-${s.id}`) добавить маленькую кнопку «глаз» с `onclick="openImagePreview(URL)"`. В view-режиме клик по аватару тоже открывает превью (как удобный bonus).

### 4. Единый стиль кнопки «глаз»

- Лайт-вариант для прайс-листа (в одну линию с «Загрузить/Удалить»): белая, иконка `eye`, цвет `text-brand-600`.
- Hover-оверлеи для интерьера/документов: круглая кнопка с иконкой `eye`, рядом с красной «trash».
- Везде `title="Просмотр"` для доступности.

## Чего не трогаем

- Логику Quill, `saveGuard`, `persistData`, рендеринг сайта `clinic-site.html`.
- Существующие URL/прайс-данные пользователя — миграция мягкая: старая запись без `dataUrl` просто показывает подсказку при попытке просмотра.

## Технические заметки

- Не используем внешние библиотеки лайтбоксов — простая DIV-обёртка + Esc-listener.
- DataURL для PDF может быть тяжёлым; при `file.size > 4 * 1024 * 1024` отказываем с тостом. В будущем (когда подключим Lovable Cloud Storage) это можно заменить на нормальную загрузку — оставлю TODO-комментарий.
