# Переключатель цен «Ведущие врачи / Главный врач»

## Проблема
В разделе процедуры есть две вкладки — «Ведущие врачи» и «Главный врач», но они декоративные: нет обработчиков клика и в данных только один массив цен `prices`. По клику ничего не происходит.

## Что сделаю

### 1. `public/clinic-site.html` — сайт
- Дать вкладкам id (`tab-lead`, `tab-chief`), повесить `onclick="switchPriceTab('lead'|'chief')"`.
- Добавить функцию `switchPriceTab(mode)`: переключает активный стиль вкладок (белый фон/тень для активной, серый текст для неактивной) и перерисовывает `#proc-prices`.
- В рендере процедуры (`renderProcedure`) запоминать текущую процедуру в `currentProc` и рендерить `proc.pricesChief` при режиме `chief`, иначе `proc.prices`. Если в режиме «Главный врач» массив пуст — показывать аккуратную плашку «У главного врача приём по этой услуге не ведётся / уточняйте по телефону».
- При входе в процедуру сбрасывать вкладку на «Ведущие врачи».
- В `DB.procedures` для всех 9 процедур добавить поле `pricesChief: []` (пустое по умолчанию — реальные цены будут заполняться через админку).

### 2. `public/clinic-admin.html` — админка
- В модалке редактора процедуры (блок «4. Варианты цен») разделить на две колонки/секции:
  - **Цены ведущих врачей** → `#pe-prices-container` (как сейчас)
  - **Цены главного врача** → новый `#pe-prices-chief-container` + кнопка «Добавить» (`peAddPriceChief()`).
- Добавить функции `peAddPriceChief()`, `peRemovePriceChief()`, рендер списка по аналогии с существующими `peAddPrice/peRemovePrice`.
- В `openProcEditorModal` подгружать `pricesChief` (default `[]` если поля нет), в `saveProcEditorModal` собирать и сохранять оба массива.
- В `defaultCatProcedures` добавить `pricesChief: []` к двум дефолтным записям.
- Патч на старые кеши: при загрузке `dbCatProcedures` дописывать `p.pricesChief ||= []`.

### 3. Связка админки и сайта
Сайт уже подтягивает `dbCatProcedures` из localStorage (если есть) — `pricesChief` оттуда будет браться автоматически.

## Чего не трогаю
Дизайн, цвета, шрифты, разметка карточек, авторизация, навигация, мобильное меню, MAX-виджет, файлы `src/`.
