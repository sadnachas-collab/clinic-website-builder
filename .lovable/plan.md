## Что делаем

Заменить 13 вызовов `confirm(...)` в `public/clinic-admin.html` на единую кастомную модалку в стиле админки. Поведение то же — отмена/подтверждение — но визуально аккуратно.

## Изменения в одном файле `public/clinic-admin.html`

### 1. Добавить хелпер `customConfirm(message, opts)` после `showToast` (строка 925)

Promise-based. Создаёт оверлей с затемнением + карточку: иконка треугольник-предупреждение, заголовок, текст, две кнопки («Отмена» серая, «Удалить» красная). Закрытие по Esc/клику на фон → resolve(false), Enter/«Удалить» → resolve(true). Подключается через существующий `lucide.createIcons()`. Использует `escapeHtml` (уже есть в файле).

API:
```js
customConfirm('Удалить категорию?', { title: 'Подтверждение', okText: 'Удалить' })
  .then(ok => { if (!ok) return; /* действие */ });
```

### 2. Заменить все 13 `confirm(...)` на `customConfirm(...).then(...)`

Сайты (строки 963, 996, 1008, 1021, 1050, 1076, 1104, 1168, 1242, 1284, 1354, 1383, 1397):
- `deletePromo`, `deleteReview`, `deleteInterior`, `deleteDoc`, `deleteFaq`, `deleteRow` (услуга), `deletePriceFile`, `deleteCatProcedure`, `deleteSpecialist`, `removeAdmin` («Закрыть доступ?»), `deleteConsumerCategory`, `deleteConsumerDocument`, `deleteAuthority`.

Шаблон трансформации:
```js
// было
function deleteX(id){ if(confirm('Удалить?')){ /* body */ } }
// станет
function deleteX(id){ customConfirm('Удалить?').then(function(ok){ if(!ok) return; /* body */ }); }
```

Для `«Закрыть доступ?»` — `customConfirm('Закрыть доступ?', { okText: 'Закрыть доступ' })`.
Для категорий и процедур — соответствующий длинный текст сохраняем 1:1.

## Чего НЕ трогаем

- Логику удаления, `persistData`, рендеры — без изменений.
- `clinic-site.html`, авторизацию, Quill, прайс-загрузку.
- `alert()` (их и нет в кодах удаления).
